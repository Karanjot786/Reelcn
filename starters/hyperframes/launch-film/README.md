# Launch film starter (HyperFrames)

The reelcn launch film: 15 seconds, 1920 by 1080, 60 fps, with a generated 120 BPM track. Its scene plan is `plan.md`, the same plan the `reelcn-motion` skill ships as `plans/launch-film.md`.

Adapt it: replace the thumbnails in `assets/thumbs/`, the renders in `assets/stills/`, the words and the logo in `index.html`, then regenerate the track and render.

```bash
node <reelcn-motion>/scripts/motion-track.mjs cues.json assets/audio/track.wav
npx --yes hyperframes@0.8.96 check
npx --yes hyperframes@0.8.96 render --fps 60 --quality looks --output out.mp4
node <reelcn-motion>/scripts/motion-check.mjs out.mp4 plan.md
```
