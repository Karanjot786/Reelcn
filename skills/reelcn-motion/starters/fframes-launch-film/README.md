# Launch film starter (fframes)

The reelcn launch film on fframes 1.1.0, Rust and SVG: 15 seconds, 1920 by 1080, 60 fps. The motion is the HyperFrames timeline replayed in `src/motion.rs` with GSAP's own ease formulas.

This is a reference film. Study its timing, its carrier and its moves, then build your own film from your plan and your material. Do not ship it with new words and images: that is the generic template this skill exists to avoid.

```bash
cargo build --release
node <skill>/scripts/motion-track.mjs cues.json audio/track.wav
cargo run --release -- inspect
cargo run --release -- render -o out.mp4
node <skill>/scripts/motion-check.mjs out.mp4 plan.md
```

The track lives in `audio/` and loads at run time, so it stays stereo. Fonts and images in `media/` are compiled into the binary.

fframes is MIT. Its h264 output uses the `libav-agree-gpl` feature, which links GPL ffmpeg. Fonts: IBM Plex, SIL Open Font License 1.1. Music: generated by `motion-track.mjs`, CC0. Everything else: MIT, like reelcn.
